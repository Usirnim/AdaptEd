# AdaptEd
Learning website which can be used to learn and has learning paths for different topics and after reading about a topic, you can can answer it with your own words, if the answer has keywords, you will be allowed to continue to the next part of section of the learning path
It also has a working login/register section

To tun it download the adapted-updated folder
Unzip/extract it if necessary
Open a terminal inside the folder
type 'python app.py'
wait for it to run
open your browser and type localhost:5000
